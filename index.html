一条海岸线，不应该只有一个长度吗？

同一条曲线，为什么换一把尺子，答案就变了？

测量规则整齐的物体，通常会得到一个稳定的数值。但海岸线有许多大小不同的弯曲。测量时使用的基本单位大小，就是这里所说的尺度。

当尺度改变，能够被捕捉到的边界细节也会改变。这种“测量结果随尺度变化”的现象，称为尺度效应。

分形小知识

尺度可以理解为我们观察或测量对象时所使用的基本单位大小。

大尺子尺度较大

跨过许多细小弯曲，路径更像一条折线。

小尺子尺度较小

捕捉更多边界细节，折线更贴近原曲线。

05 / 09

这些数据，有没有数学规律？

把“尺子大小”和“测得长度”写成变量，寻找一个能够描述变化的函数。

设量测尺度为 x，测得长度为 y。

y = f(x)

研究目标，是寻找一种能描述这种变化的函数关系。

模型一

一元一次函数

用直线描述变化。

R² = 0.86
模型二

反比例函数

用倒数关系描述变化。

R² = 0.75
模型三

幂函数

在本研究数据和尺度范围内，拟合程度更高。

R² = 0.99
候选模型→幂函数→双对数变换→斜率 n→D = 1 − n
展开了解数学原理

幂函数写作：

y = c xn

本研究双对数图使用自然对数，关系变成：

ln y = n ln x + ln c

在双对数坐标中，数据若近似一条直线，就可以利用直线斜率 n 描述变化，再计算：

D = 1 − n
本研究结果｜数据来源：最终研究报告

双对数坐标下的自然岸线数据

横轴为 ln(量测尺度 / m)，纵轴为 ln(岸线长度 / km)。图中拟合线直接使用最终报告关系式：Y = −0.1842X + 5.6267；正文中的D和R²仍以最终报告为准。

双对数坐标下的数据近似呈线性关系，是本研究采用幂函数近似描述尺度效应的重要依据之一。

一条海岸线，到底有多长？

答案不仅与海岸线本身有关，也与你用什么尺度观察它有关。

科学不仅要寻找规律，还要不断检验规律在什么条件下成立。
